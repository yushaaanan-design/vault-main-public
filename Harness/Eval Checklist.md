# Done-checklist for any task (run before saying "done")

- [ ] I checked the real output, not only that the command ran (file exists, numbers sane, image looked at).
- [ ] Anything I guessed is labelled as a guess; anything verified says how.
- [ ] Failures and corrections are in the right Lessons file (central or the vault's own).
- [ ] The project's run-log has this step; the Resume Protocol still matches reality.
- [ ] Secrets, cookies and personal data are not in notes, git or chat; downloads outside OneDrive and vaults.
- [ ] Destructive actions had stated facts and a rollback line.
- [ ] The task's line in `Central To-Do List.md` is ticked/removed (search the list for the task's keywords, not only the exact item), and my reply says which notes I updated.
- [ ] Tool or install changes recorded in `Resources/tools-in-use.md` and the system settings guide when system-level.
- [ ] A model-log row was added for the finished chunk (rating only from the user's own words).
