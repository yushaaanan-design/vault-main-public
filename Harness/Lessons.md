# Cross-project lessons (symptom, cause, fix). Newest first.

| Date | Symptom | Cause | Fix / rule |
|---|---|---|---|
| 2026-10-22 | Python tools and winget fail with certificate errors (`CERTIFICATE_VERIFY_FAILED`, winget `0x8a15005e`) | Norton "Web/Mail Shield" re-signs HTTPS; Windows trusts its root, Python's certifi does not | Use the `truststore` package (Windows cert store) in a wrapper, never disable certificate checks. winget: add `--source winget`. Applies to every Python download on this PC |
| 2026-10-22 | `npx rea-agents setup` refused: auto mode "Self-Modification" | it edits `~/.claude.json` and installs a skill | Never retry or route around. Give the user the exact `! command` or a permission rule. Editing the user's CLAUDE.md worked when the user had asked for it and the gate facts were stated |
| 2026-10-22 | GateGuard hooks block the first Bash, PowerShell, Write or destructive command | policy hooks ask for facts | State the 3-4 facts in text right before retrying: what it does, callers, data fields, the user's words verbatim. No workarounds |
| 2026-10-22 | Background jobs killed, "system low on memory" | 16 GB RAM: Whisper + browser + Claude at once | One heavy job at a time; jobs wait for 2.5 GB free RAM; when the harness reaps a job, report it and do not restart it on my own |
| 2026-10-22 | Bash tool: `unexpected EOF while looking for matching '` | a long heredoc followed by more commands after its terminator | Heredoc script in its own call with nothing after it, or use the Write tool. Backticks inside a heredoc produce a harmless stray error, check the file was written |
| 2026-10-22 | A loop created junk folders, runs failed | Windows backslashes plus `$var` inside double quotes in bash | Pass Windows paths with forward slashes (`C:/dev/...`) or build arguments in Python. `python -I` does not understand Git-Bash `/c/...` paths, use `C:\` or `C:/` |
| 2026-10-22 | I stated how a tool works ("probably just slices video") before inspecting it | guessed from marketing pages | Inspect the artefact (strings, files, real output) before explaining it; label guesses as guesses |
| 2026-10-22 | Library API mismatch crashed a pipeline at the first call | PyAV 19 dropped an argument the Whisper library still passes | Patch inside the run, keep the shared environment untouched; record the version pair in the project's lessons |
| 2026-10-23 | Installed two plugins and removed a finished item, but left the to-do line, tools-in-use, repo status and run-log stale; user: "if you do something, then why don't you cut it off the to-do list? This is a harnessing problem" | No close-out step after a task; I treated the notes as a separate request | Every finished task ends with a close-out in the same turn, before replying: (1) tick/remove its line in `Central To-Do List.md` (also lines that only partly match, e.g. "installed X"), (2) tools-in-use row + change log if anything was installed/changed, (3) github-repos status, (4) project run-log/STATE. Say in the reply which notes were updated. Also check "already done?" with `claude plugin list` before treating it as new work (cross-project) |
| 2026-10-23 | Stopped a long overnight list early and handed it back to the user | treated size of the list as a reason to check in | The user decides when work ends. Finish the list or keep looping batches with a run-log entry after each; never say a turn has to end (cross-project) |
| 2026-10-23 | Reported measured data as analysed / read | no shared status words | Use measured / read / done in every project; only by-eye rows count as read (cross-project) |
| 2026-10-23 | Pooled statistics across groups gave a false signal | confounded by group (streamer) | Compare inside the group first, state the confound, label hypotheses as unconfirmed (cross-project) |
| 2026-10-23 | A small local model used as a judge gave almost every moment 7-8 and echoed the prompt text; the first ranking looked fine on numbers | never tested the judge for spread before trusting it | Before wiring any judge or checker in, run it on a clearly good and a clearly bad example and look at the output; if scores do not spread, use a stronger model for that step (cross-project) |
| 2026-10-23 | The Voice Check let through a label accusing a real person of cheating | rules only covered slurs and length; the local checker is weak | Try the check on adversarial examples (accusations, quotes not in the source) when building it, and look at the first real output by eye (cross-project) |
| 2026-10-23 | A download error was reported as "wants a login" when the real cause was a Norton HTTPS certificate failure | the handler matched the words "confirm you" in an unrelated yt-dlp hint | Print the real error text before believing a friendly summary; match narrow phrases, not common words (cross-project) |
| 2026-10-23 | A job was blocked for VRAM because the local model server (Ollama) itself held the memory | a resource gate counted the resident model as "busy" | Gate on a resource only for steps that really need it; let the model server manage its own load (Assistant) |
| 2026-10-23 | `ytsearchdate` search prefix silently stopped working in yt-dlp | upstream change | Every source adapter reports "returned nothing" in the digest header, so a dead source shows up the first night (Assistant) |
